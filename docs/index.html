Takes a minute. macOS will complain once – that's expected.

Download and drag to ApplicationsOpen Badgertop.dmg and drag the badger into the Applications folder.
Open it once – macOS blocks itThen go to System Settings → Privacy & Security, scroll down and click Open Anyway. Badgertop isn't notarized (Apple charges $99 a year), so this is the only way the first time.

Questions

Is it private?

Badgertop reads only window positions and the name of the active app – never window contents or what you type. Its only network request is a daily check for a new version on GitHub.

How do updates work?

Once a day it checks for a new release. When there is one, a badger brings you a note – click it to download.

Will it slow my Mac down?

No. It uses a few percent of one CPU core and sleeps in its burrow when you're away.

They're in the way – can I hide them?

🦡 menu → Hide everything. They also hide automatically in full-screen apps.

How do I uninstall it?

Quit it from the 🦡 menu and drag Badgertop from Applications to the Trash.

Not yet. Maybe one day.
